# muKG A/B/C 正式实验协议

协议版本为 `formal-abc-v2`。2026-11-06 确认三组共同训练预算为 1000 epoch。运行冻结目录中的 `freeze.json` 绑定本协议、源码、数据、环境、验收回执与 27 项任务。冻结阶段止于检查和两步 CUDA 预检。正式任务由明确的单任务调用启动。

## 共同配置

| 项目 | 固定设置 |
|---|---|
| 数据 | FB15k-237 官方 train、valid、test，实体及关系映射固定 |
| 模型 | TransE 250 维，L1 距离，fdfd880 历史初始化，实体不归一化 |
| 损失 | logistic_adv，margin 7，adv 2 |
| 优化 | Adam，学习率 0.0005 |
| 批次 | 5000 条正样本，每条 150 个负样本，保留尾批 |
| 设备 | 一张 RTX 3070 上训练；CPU 线程数 10 |
| 评估分块 | 32 条查询、2048 个实体 |
| 配对 | 同种子初始参数及正样本批次顺序一致，保存身份哈希 |

A 使用历史 CPU 采样，保留轮内无放回、方向选择、最多 10 轮和最后一轮兜底。B 与 C 使用同一张量采样算法，每条正样本固定 75 个头替换和 75 个尾替换，有放回，过滤原正样本和训练集真三元组，最多 64 轮。B 在 CPU 执行采样，C 在 GPU 执行采样，各自生成随机负样本。

数据清单绑定五个文件的 SHA-256。train 和 valid 及映射需与完成诊断一致，test 与历史官方划分档案一致。冻结准备只读取 test 字节用于哈希。

## 任务与测量

| 阶段 | 清单 | 计划顺序 |
|---|---|---|
| 独立吞吐 | S 组 15 项，种子 201–205 | ABC、BCA、CAB、CBA、BAC |
| 分阶段计时 | T 组 3 项，种子 201 | ABC |
| 质量 | Q 组 9 项，种子 101–103 | ABC、BCA、CAB |

吞吐和 trace 各完整预热 1 epoch。模型、优化器、采样器及随机数状态连续保留，第 2 至 6 轮为测量期。每轮覆盖全部 272,115 条正样本，包含 54 个完整批次及 2115 条的短批次。吞吐主计时涵盖正样本准备、采样、传输和模型更新，额外同步仅设于轮边界。Trace 采用独立任务和分阶段同步，完整与短批次分别汇总，采样阶段记为负样本准备与传输。峰值显存为整轮训练路径的 allocated 和 reserved。独立吞吐结果用于主速度判断。

质量固定完成 1000 epoch，每 10 epoch 做一次完整验证。最佳 checkpoint 取总体双向验证 MRR 最大值，并列选最早轮次。训练完成后对该 checkpoint 进行一次官方测试。验证过滤 train＋valid，测试过滤 train＋valid＋test。并列使用平均名次，保存完整排名、头尾总体 MRR 和 Hits@1/3/10。固定轮数是共同预算，训练充分性结合曲线讨论。

## 预注册判断

吞吐任务先取五轮平均耗时，按同种子形成 A/C、A/B、B/C 耗时比。质量对照报告 C/A、B/A、C/B 的总体及头尾测试 MRR 比。报告逐种子比值、几何均值和对数比值的双侧 95% t 区间。主速度比 A/C 的目标为大于 1，主质量比 C/A 的目标为至少 0.95。分别判断点估计与区间下限。缺失配对时标记证据不完整。单种子 trace 描述时间构成。

整体路径收益由 A/C 衡量。同规则下的设备与传输差异由 B/C 衡量。A/B 包含采样规则与 CPU 实现的共同变化。记录训练、验证、测试与总墙钟，保留验证指标与时间曲线所需数据。

## 结果与失败记录

正式入口每次只启动指定任务，先核对冻结记录和当前代码、数据、环境，检查 GPU 互斥和占用。每次尝试单独落盘，保存源身份、配置、种子、初始权重和批次顺序哈希、原始日志、计时、遥测、状态及材料哈希。

中断后显式启动同种子同配置的新尝试，从头训练。完整有效结果按首个通过校验的尝试选取。外部干扰由事件或遥测记录支持，失败和中断原样保留。持续 OOM、非有限损失、协议不匹配和采样耗尽须调查。改变科学配置需要新协议记录。

## 冻结验收与预算

- 核对闭合诊断存档及原始运行清单，使用诊断源码复算报告。验证正式路径的共同模型、采样、评估和更新函数。
- CPU 与实际 CUDA 检查通过。三组在 5000 批次下分别执行两步训练更新，检查有限损失与显存余量。峰值 reserved 须低于总量的 90%。OOM 与余量不足各自记录。5000 未通过时暂停冻结并记录。
- 冻结目录保存源码快照、验收记录、五文件身份、GPU 环境、配置、统计规则及完整任务表，重新读取校验。

诊断外推九项质量约 39.84 小时，15 项吞吐约 0.41 小时。已估部分含 30% 余量约 52.32 小时，trace 与额外检查另计。1000 epoch 延续固定预算评估；诊断曲线对充分训练的判断有限。

阶段验收以冻结目录状态 `frozen_awaiting_start` 为准。每项任务的命令、估时和目录见对应 `TASKS.md`。
