# mechanism-v1 独立源码审阅记录

审阅采用一个独立Codex上下文，以只读方式检查机制代码、计划和测试。审阅者未执行GPU任务或实验。审阅结论为修正后再冻结。

| 发现 | 影响 | 处理和证据 |
|---|---|---|
| 未显式恢复仍可越过中断任务继续队列 | 违背停止边界 | CPU回归复现，run在未解决中断处停止 |
| 未知worker退出无法显式恢复 | 队列无法完成 | CPU回归复现，未知退出等待--resume后新尝试 |
| 只有sidecar的启动中断复用同编号 | 恢复永久FileExistsError | CPU回归复现，分类保留已预留尝试，显式恢复分配下一个编号 |
| 预检门槛遗漏验证峰值 | 90%显存检查可能误通过 | 实际CUDA小型回归复现，峰值读取移到完整训练/验证之后 |
| 唯一组输出为固定槽位而非首次接受顺序 | 轻微规范差异，无序子集和当前损失不变 | 在设计和执行记录中明确固定槽位规则 |

实施者另外检查了未封存完成状态恢复、检查源码保存、闭合结果不可写入、完整训练集碰撞复核和观测统计重算。相关新检查已通过。

科学范围保持四策略、三个种子和1000轮。代码审阅不替代实际显存预检、耗时测量和最终结果复核。最终状态以冻结验收和逐任务记录为准。
