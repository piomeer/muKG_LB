# muKG 采样机制对照设计草案

日期为 2026-11-08。用户已确认四组、三个新种子、1000轮的设计，并批准详细执行计划。当前进入实现与检查，实际源码、环境、输入和任务在预检后冻结。下文保留设计依据和方案取舍，执行安排以 `../plans/2026-11-08-sampling-mechanisms-execution.md` 为准。

## 1．问题与已有依据

结果及推理依据见 `../../formal_v1/RESULTS_REFLECTION_2026-11-08.md`。本轮正式 C/A 测试 MRR 比为 0.922624，B/A 为 0.919569，C/B 为 1.003322。效率收益已确认，下一阶段主要研究质量差距。

待回答三个问题。

1. 每条正样本固定混合两个方向，是否影响预测质量？
2. 允许重复负样本是否影响质量，并与方向组织发生交互？
3. 自对抗权重、梯度和实际采样统计，能否为质量差异提供一致的机制解释？

改进候选的目标继续是缩小相对历史 A 的质量损失，同时保留端到端训练加速。已有 5% 界限继续保留。所有已完成结果按原协议报告。

## 2．方案选择

| 方案 | 优点 | 代价与限制 |
|---|---|---|
| 仅比较当前 C 与单方向候选 | 最少两个组，直接检验方向组织 | 重复因素与交互仍无法解释 |
| 方向组织×重复规则的 2×2 对照 | 四组可拆解两因素并观察交互 | 三种子需 12 个验证训练任务 |
| 同时开展方向、重复、过滤、重试和损失的全面消融 | 覆盖更广 | 任务膨胀，原兜底触发频率尚未知，必要性不足 |

用户已选择第二种。先以相同模型、损失和严格训练过滤构造四组。损失权重分配先观测，是否增加分方向归一化损失对照由单独决策门处理。

## 3．四组与比较含义

全部在 GPU 上采样和训练。四组均使用完整训练集三元组过滤，拒绝原正样本，最多 64 轮，失败明确退出。

| 组别 | 每条正样本的方向组织 | 同一正样本内重复 | 作用 |
|---|---|---|---|
| M00 | 固定 75 头＋75 尾 | 允许 | 当前 C 规则在新机制版本中的同期对照 |
| M10 | Bernoulli(0.5) 选择一端，该条全部 150 个负样本保持此方向 | 允许 | 与 M00 比较方向组织 |
| M01 | 固定 75 头＋75 尾 | 禁止完整负三元组重复 | 与 M00 比较重复因素 |
| M11 | 每条选一端，150 个负样本保持该方向 | 禁止完整负三元组重复 | 检查两个因素的组合和交互 |

M10/M11 的方向随机数每条正样本抽取一次，重试保持方向。整批和整轮比例只在期望上各半，不能称为每批严格均衡。M01/M11 从对应方向的合法实体中均匀无放回产生最终候选。跨正样本允许重复，跨 batch 也允许重复。有限重试失败仍保留为失败。

M01 每个方向分别有 75 个唯一候选。M11 同方向有 150 个唯一候选。通过去除同一轮和历史已接受候选的重复来完成拒绝采样，已经接受的候选优先于新候选，同轮按槽位保留第一个。实施审阅后明确输出保留固定槽位，维持头尾布局；原草案的首次接受输出顺序不作为最终规范。当前TransE与损失对同行负样本置换不敏感，无序子集的均匀性不受这一顺序选择影响。在对应方向的合法实体集合中，每个大小为 K 的无序子集应等概率。有限轮数可能失败，因此成功条件下的子集分布和失败概率要分别验证。小实体空间枚举有限候选序列，核对子集概率；大空间采用预先规定的分布检查。

M10/M11 只接近 A 的首轮方向组织。A 可在重试中换方向，且其无放回只在轮内成立，还保留最后一轮兜底。因此四组都使用明确的新名称，不能称为完整恢复原历史语义。

历史 A/B/C 结果继续提供上下文，不能与新组的不同种子组成配对。旧 C 不替代新版本 M00 的同期对照。

## 4．共同设置

沿用 TransE 250 维、L1、历史初始化、不归一化、logistic_adv margin=7、adv=2、Adam 学习率 0.0005、150 个负样本、batch size=5000、CPU 线程 10、官方 FB15k-237 train/valid/映射。

训练阶段仅解析 train/valid 及映射。验证过滤 train＋valid，完整双向 filtered MRR、平均并列名次，报告头尾和 Hits@1/3/10。模型、损失、优化器、正样本顺序、验证频率和轮数四组一致。

新采样器使用显式、隔离的随机数状态，方向与候选随机流分别记录。同种子四组共享初始权重和全部正样本顺序。即使组间消耗随机数不同，也不能影响初始化或正样本排序。不要求具体负样本逐项一致。

如唯一采样在 5000 下无法满足共同显存预留条件，先调查实现。确需改变共同 batch 时另行修订草案并重新冻结全部四组，不能只调整唯一组。

## 5．阶段 O：固定参数下的机制观测

该阶段使用同一权重下的多策略对照，减少不同训练轨迹对即时解释的影响。

提议设三个参数锚点，共同新初始化 seed 401、历史 A-101 最佳 checkpoint、历史 C-101 最佳 checkpoint。两个历史 checkpoint 的轮数不同，应将三个锚点作为独立条件分别报告，不能合并为独立随机种子或据此推断学习轨迹。所有输入来自固定训练 batch。

每个锚点使用固定的 4 个完整训练 batch 和 1 个短 batch。四种机制策略各用候选 seeds 601、602、603 重复采样，总计 180 个策略—参数—batch 观测。锚点文件和训练 batch ID 需写入清单。

保存以下观测。

- 实际头尾数量、唯一三元组数、重复比例、拒绝数、重试轮数、训练集碰撞和耗尽。
- 负样本分数的头尾分布、头尾自对抗权重总量、权重熵、有效样本量 `1/sum(w²)`。
- 总梯度、负项梯度及头尾贡献的范数和余弦相似度；明确总损失中正负项各自的系数。
- 重复三元组合并后的权重集中度，避免只看按位置计算的有效样本量。

同一参数与候选上，仅对混合方向的 M00/M01 另算“各方向分别 softmax 后各给 0.5 权重”的反事实损失及梯度。实际损失、反事实和梯度分解均沿用原实现对权重执行 detach 的语义。头负项、尾负项和正项按原系数相加，应重组完整梯度。零梯度分量的余弦记为未定义，并保存原因。

这些是三个具体参数锚点下的即时观测，不做优化更新，不产生模型质量或整个训练期间的机制结论。单方向组的全部权重自然落于所选方向，不能把这个事实误判为异常不均衡，也不能给空方向分配一半权重而改变负项总尺度。自对抗损失本来就会强调难例，混合组存在方向权重集中本身也不能证明训练机制有缺陷。

另设 `O-A` 历史采样观测任务，使用相同的 4 个完整训练 batch 和 1 个 2115 条的短 batch，配 seeds 601、602、603，共 15 次调用、66345 次正样本处理。记录实际候选总数、A 第 10 轮兜底的触发数与分母、跨重试重复与方向变化。带观测的 A 必须在相同随机状态下与现有 A 逐项输出一致。重复处理的相同正样本不能当成新的独立查询。零次观测只支持该采样范围内未发生，不能当成全训练从未发生。

观测使用独立进程，涉及梯度的步骤不更新参数。其耗时不进入正式吞吐。分数和梯度属于未来执行内容，本次只完成设计。

## 6．阶段 V：四组同预算验证实验

提议使用此前质量实验未用的 seeds 401、402、403，每组固定完成 1000 epoch，每 10 epoch 完整验证。提议 12 个完整任务。

| 配对种子 | 组别执行顺序 |
|---|---|
| 401 | M00 → M10 → M11 → M01 |
| 402 | M10 → M01 → M00 → M11 |
| 403 | M01 → M11 → M10 → M00 |

每个任务独立进程、独立目录，完成即退出。单张 GPU 一次一个 worker。质量低、速度慢或未见改善均作为有效结果保留。是否连续调度及重试策略在之后实施计划中明确。

本阶段不评估测试集。每组同时报告最佳验证 checkpoint 和共同第 1000 epoch 指标，保存全部验证曲线和排名。最佳值仍采用最大总体验证 MRR，并列取最早。

主机制比较预先定为 M10/M00，用于检查有放回条件下的方向组织。补充比较 M01/M00、M11/M01、M11/M10，以及四组交互。所有比较报告逐种子数据，避免选择性呈现。

对每个种子的最佳验证 MRR 记为 y。方向主效应的对数尺度定义为 `0.5 * [log(y10/y00) + log(y11/y01)]`，唯一性主效应为 `0.5 * [log(y01/y00) + log(y11/y10)]`，交互为 `log(y11/y01) - log(y10/y00)`。同样计算共同第 1000 epoch 的比较，并结合全程曲线，避免把各组不同最佳轮次误认为同一训练时点。报告原始量和三种子分布，探索性区间沿用 log-t 方法并披露小样本与多比较限制。它们解释这两个明确实现因素在当前条件下的影响，不能证明所有采样语义的总体因果关系。

最佳验证指标参与候选选择，不能代替后续最终质量确认。当前 12 个任务承担机制探索，不宣称新的正式测试达标。

## 7．权重机制的决策门

方向组织的干预同时改变每条正样本的负样本构成和梯度相关性。即便 M10 优于 M00，也不能单独证明 softmax 竞争是原因。

观测与四组训练完成后，提交方向权重原始指标、局部梯度变化和跨种子质量差异，再讨论是否设计损失控制组 L。当前草案不设自动触发 L 的结果门槛。L 的待讨论定义是保持 M00 的候选规则，对 75 个头候选和 75 个尾候选分别计算 softmax，各给负项总权重的 0.5，正项和正负项整体比例保持原值。

L/M00 才能直接检验“共享归一化与分方向归一化”这一干预。L 改变训练损失，需要独立版本、明确的任务清单和确认。它不是本草案自动追加任务。如果两类观测不一致，应报告不一致，并在新设计中说明继续或停止的理由。

## 8．候选选择与下一阶段确认

在全部 12 个任务完成后，以三个种子的最佳总体验证 MRR 均值最高者作为唯一候选，比较 M10、M01、M11 和 M00。均值完全相同按预先顺序 M00、M10、M01、M11 取先者。效率、头尾差异和复杂度同时报告，但不能看过结果后更换主排序标准。

如果改进组均未超过 M00，记录没有发现质量改善。若最高均值与 M00 非常接近或种子方向不一致，注明选择不稳定。选出候选不等于证明改善或达到 0.95。

下一阶段如决定确认候选，需另行冻结候选、比较组、新种子、1000 轮预算和正式统计方法。建议届时讨论历史 A、同期 M00、选定候选三组，以支持候选相对历史质量和相对当前规则改进的完整比较。机制矩阵全部在 GPU 执行，不能据此证明新候选的 CPU/GPU 加速，需要时为选定候选增加匹配 CPU 对照。

已经查看过 FB15k-237 测试结果，新阶段属于结果驱动的探索。新随机种子不能消除测试集在研究过程中的既有暴露。若再次在同一官方测试集评估，应如实披露并解释为该数据集上的后续确认，不能声称完全独立的盲测。是否需要额外独立数据验证另行讨论，当前不扩展数据集。

## 10．正确性和材料要求

后续实施在当前 `codex/formal-v1` worktree 的 `src/py/experiments/formal_v1/` 上增加版本化能力。历史闭合运行及 source 快照保留原身份，新路径建议使用 `output/results/mechanism_v1/`。

必须覆盖以下新增风险。

- 同期 M00 与旧 C 核心规则一致。旧 C 使用 CUDA 全局随机流，新版使用显式 Generator。桥接检查在模型初始化后复制旧流状态到新 Generator，对同一 batch 核对采样输出和后续状态，再核对分数、损失、梯度及一步更新。该检查不要求新版本同 seed 的全部训练负样本与历史任务逐项一致。
- 单方向保持、方向概率、75/75 布局、各组唯一性和正负对应。
- 空输入、短 batch、候选不足、完整三元组过滤和 64 轮耗尽。唯一合法候选不足时明确失败。
- 小实体空间的无放回分布，重复消解规则的正确性及理论约束。
- 隔离随机流不改变初始化和正样本顺序，观测不改变采样输出或模型参数。
- 权重按正样本归一化，方向质量分配之和为 1；已知小分数输入上的梯度分解可重组原梯度。
- 训练吞吐不包含探针。观测与训练任务分别保存材料，峰值显存说明完整训练路径范围。
- 固定训练轮数、模型选择、train＋valid 过滤和测试集不可访问检查。
- 拒绝覆盖、用户停止、进程互斥、失败保存、缺失配对处理及分析复算。

每个任务保存协议和配置、源码及数据身份、种子和随机流标识、初始权重和正样本顺序、原始排名和统计、checkpoint、时间及资源记录、状态和全部尝试、文件大小与 SHA-256。记录开启探针的采样位置，采样位置与观测方案在训练前固定。

## 11．论文可用材料和完成标准

本阶段应产出两个因素的语义对照、完整四组验证结果、头尾及时间曲线、重复和权重观测、梯度证据、失败和未支持假设，以及候选选择记录。

对负结果采用对称判断。方向改善、唯一性改善、两者交互、全部不改善都可构成有效结论。观测与训练结果一致时可说“支持该机制解释”，只凭权重偏向不能证明最终 MRR 下降的原因。

实施验收通过、12 个验证任务全部有效完成、观测齐全且报告可复算，才称机制矩阵证据完整。任务有明确终止原因时可以执行结项，但需标记证据不完整及缺失比较。候选超过 M00、达到历史 A 的 95%、充分收敛均需分别判断。正式质量和速度的后续确认拥有独立完成标准。
